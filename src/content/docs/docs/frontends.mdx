## Quickgui

`quickemu` 与 `quickget` 是为终端设计的，但也可以使用图形界面：

- **[Quickgui](https://github.com/quickemu-project/quickgui)**，作者 [Mark Johnson](https://github.com/marxjohnson) 与 [Yannick Mauray](https://github.com/ymauray)。

[![打包状态](https://repology.org/badge/vertical-allrepos/quickgui.svg?header=quickgui)](https://repology.org/project/quickgui/versions)

在 Ubuntu 上安装 Quickgui：

```shell
sudo add-apt-repository ppa:flexiondotorg/quickemu
sudo apt update
sudo apt install quickgui
```
