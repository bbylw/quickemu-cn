---
title: 安装 SPICE 代理（客户机内）
---

在客户机中安装以下代理即可获得完整体验：

- **SPICE 代理**（`spice-vdagent`）：启用宿主与客户机之间的复制/粘贴以及 USB 重定向。Debian/Ubuntu 上执行 `sudo apt install spice-vdagent`。
- **SPICE WebDAV 代理**（`spice-webdavd`）：启用宿主与客户机之间的文件共享。Debian/Ubuntu 上执行 `sudo apt install spice-webdavd`。

用 `quickget` 创建的 Windows 客户机已自动安装所需驱动。
